# Vault root — start here

Shared company knowledge vault (Obsidian folder + Claude Code working
directory, same Markdown files). **Mode:** company · **Note language:**
{{LANGUAGE}} (folder names stay English).

**Rules here:** [CLAUDE.md](CLAUDE.md) is binding. Two company rules on
top: a note counts as company truth only with `status: stable` AND a
filled `verified:` — anything else is a proposal, and everything under
`00-inbox/suggestions/` is a proposal by definition. Every note names an
`owner:`. `confidentiality:` is a label, not access control.
**Search before reading:** `python3 .tools/search.py <terms>` from this
folder, then open only the hits. `python3 .tools/hygiene.py` for
orphans, dead links and notes missing from an index.
**NOT here:** anything about a named employee beyond "currently holds
role X", and any private note — this vault is shared.
