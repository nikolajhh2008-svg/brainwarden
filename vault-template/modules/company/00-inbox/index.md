# 00-inbox

Raw, unsorted captures — one file per thought, nothing here is finished
and nothing here is company truth.

**Rules here:** the ONE folder without frontmatter rules and without a
naming convention — friction here costs captures. File names
`YYYY-MM-DD-slug.md`. Never cite a file from this folder as an
established fact; it is a thought, not a result. The folder AND
`suggestions/` go to ZERO at every weekly review: released into a real
folder (with `status: stable` + `verified:`), or dropped.
**NOT here:** released content — SOPs in
[../50-processes/](../50-processes/index.md), roles in
[../60-roles/](../60-roles/index.md), knowledge in
[../30-knowledge/](../30-knowledge/index.md), decisions in
[../40-decisions/](../40-decisions/index.md). Private notes belong in a
personal vault, not in a shared one.
