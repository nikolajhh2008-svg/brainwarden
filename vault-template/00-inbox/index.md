# 00-inbox

Raw, unsorted captures — one file per thought, newest wins, nothing here
is finished.

**Rules here:** the ONE folder without frontmatter rules and without a
naming convention — friction here costs captures. File names
`YYYY-MM-DD-slug.md`. Never cite a file from this folder as an
established fact: it is a thought, not a result. The folder goes to ZERO
at every weekly review; if an item survives a review it is either filed
or deleted, never "kept for later".
**NOT here:** anything already processed — knowledge belongs in
[../30-knowledge/](../30-knowledge/index.md), work with an end date in
[../10-projects/](../10-projects/index.md), a made decision in
[../40-decisions/](../40-decisions/index.md).
