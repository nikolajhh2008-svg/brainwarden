# examples

Style references for the kit — what a finished note of each type looks
like. Read before writing the first note of a type.

**Rules here:** these are NOT vault content and are never copied into a
vault. They exist to set the BAR: a note that looks like these has
earned its frontmatter. In particular `maturity: evergreen` means idea +
named evidence + one concrete case + an honest limit, ~100–400 words —
see the knowledge example. A four-line note is a `seed`, whatever its
frontmatter claims. `verified:` appears here because a human wrote these;
an agent never sets that field on its own work.
**NOT here:** the blank shapes to copy — those are the vault's
`_templates/` (`vault-template/_templates/`, plus the company templates
under `vault-template/modules/`).
